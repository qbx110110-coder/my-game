# 连连看游戏 (Connect the Tiles Game)

一个用 HTML、CSS 和 JavaScript 构建的经典连连看游戏。

## 游戏规则

1. **目标**: 消除棋盘上的所有方块
2. **操作**: 点击两个相同的方块进行匹配
3. **得分**: 每成功匹配一对方块获得10分
4. **提示**: 使用"提示"按钮获得匹配建议

## 功能特性

- 🎮 8×8 棋盘布局（可自定义大小）
- 🎨 彩色渐变界面设计
- ⏱️ 实时计时器
- 📊 动态分数和进度显示
- ✨ 流畅的动画效果
- 💡 游戏提示功能
- 📱 响应式设计，支持移动设备
- 🎯 游戏结束提示

## 如何运行

1. 在浏览器中打开 `index.html`
2. 点击"新游戏"开始
3. 点击两个相同的方块来匹配它们
4. 消除所有方块获胜！

## 按钮功能

- **新游戏**: 开始全新游戏
- **提示**: 显示可匹配的方块对
- **重置**: 取消当前选择

## 技术栈

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)

## 游戏截图

游戏界面包含：

## 自定义

您可以轻松修改以下内容：

### 改变方块数量
编辑 `game.js` 中的 `gridSize`:
```javascript
this.gridSize = 8; // 改为 6, 10 等
```

### 改变方块类型
编辑 `emojis` 数组：
```javascript
this.emojis = ['🌟', '🎈', '🎁', ...]; // 添加您自己的emoji或符号
```

### 改变颜色主题
编辑 `style.css` 中的渐变色和主题颜色
